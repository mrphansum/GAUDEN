================================================================================
  HOME APPLICATION FIX — CALL CHAIN (HỌC TẬP)
  Dữ liệu đi từ hàm nào → qua đâu → tới server → về UI
================================================================================
  Đọc kèm:
    - docs/LUONG_HOAT_DONG.txt  (nghiệp vụ / ai được làm gì)
    - docs/DATA_FLOW.txt        (JSON shape, Mongo lưu gì)
  File NÀY: chuỗi gọi hàm THẬT trong code (tên file + tên hàm).
  Mục tiêu: bạn trace được từng bước khi học.
================================================================================


CÁCH ĐỌC FILE NÀY
--------------------------------------------------------------------------------
  Ký hiệu:
    [UI]     = màn SwiftUI, user chạm / gõ
    [iOS]    = class/struct Swift trong app
    [NET]    = HTTP request ra ngoài
    [API]    = Express route trên server
    [SVC]    = service backend
    [DB]     = MongoDB qua Mongoose model
    -->      = gọi tiếp
    <--      = trả kết quả về

  Layer iOS (từ ngoài vào trong):
    View (UI)
      --> ViewModel / private func trên View
        --> AppState (session)
          --> *Service (Auth / Module / IAP)
            --> APIClient (HTTP)
              --> TokenStore / KeychainStore (token)
                --> SERVER

  Layer backend (từ ngoài vào trong):
    index.ts  listen
      --> app.ts  mount routes
        --> routes/*.ts  handler
          --> middleware (auth)
            --> services/*.ts
              --> models/*.ts  MongoDB

# PHẦN 10 — APIClient CHI TIẾT (MỌI REQUEST ĐỀU QUA ĐÂY)
################################################################################

File: Core/Networking/APIClient.swift
Base URL: AppConfig.apiBaseURL  (Core/Config/AppConfig.swift)

func request<T: Decodable>(path, method, body, authorized, retry...)
  |
  +--> requestData(...)
        1. URL(string: path, relativeTo: apiBaseURL)
        2. URLRequest: method, Accept/Content-Type JSON
        3. nếu authorized:
             tokenProvider() --> TokenStore.loadTokens().accessToken
             Header Authorization: Bearer ...
        4. nếu body: JSONEncoder + AnyEncodable --> httpBody
        5. URLSession.shared.data(for: req)   // thật sự ra mạng
        6. đọc HTTPURLResponse.statusCode
        7. 401 + authorized + retry --> refreshIfNeeded() rồi gọi lại 1 lần
        8. không 2xx --> decode APIErrorBody, throw APIError.http
        9. return Data
  |
  +--> JSONDecoder().decode(T.self, from: data)


Cấu hình callback lúc AppState.init:
  api.tokenProvider = { tokenStore.loadTokens() }
  api.refreshHandler = { try await auth.refreshTokens() }
